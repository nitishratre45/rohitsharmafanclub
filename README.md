# Rohit Sharma FanClub — Hitman 45

Independent fan-made site for Rohit Sharma, with a navy/cyan/orange visual system and a separate Admin Studio.

## Sections
Home, career stats, batting/bowling/Stats Explorer, attributed Rohit photo gallery, matches, records, news, videos, search, Fan Zone and wallpaper maker. Modular paths are maintained for completed matches, match details, scorecards and one-over analysis.

## Data integrity
Career statistics and match records are stored snapshots, not live score feeds. Ball-by-ball/death-over totals are not displayed until a validated Rohit-specific dataset is connected. Do not invent figures or label old data as live.

## Photo licensing
The gallery uses externally hosted Wikimedia Commons images and links each item to its original file page, creator/license information and attribution. Check each source page before reuse and retain required attribution/share-alike terms. This independent fan project is not affiliated with BCCI, ICC or Rohit Sharma.
